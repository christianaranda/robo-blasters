## Supported Formats
- MP3 (.mp3) - Recommended for best browser compatibility
- OGG (.ogg) - Good alternative
- WAV (.wav) - Large file size but high quality

## Playlist System
The game automatically cycles through all music tracks in the playlist. When one track ends, the next one begins. Tracks play in sequence and loop back to the first track after the last one.

## Note
Due to browser autoplay restrictions, music may not start automatically until the user interacts with the page (clicks the start button).
